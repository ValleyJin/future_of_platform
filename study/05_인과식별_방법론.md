# 5장. 인과 식별 방법론: 알고리즘의 몫과 사람의 몫을 어떻게 가르는가

## 5.1 왜 관찰만으로는 안 되는가

어떤 사용자가 극단적인 영상을 많이 봤다는 사실을 관찰했다고 하자. 이것은 세 가지 원인이 뒤섞인 결과다.

- 알고리즘이 그 영상을 밀어줬다 (알고리즘 큐레이션)
- 사용자가 그 영상을 찾아다녔다 (사용자의 취향)
- 그런 영상이 많이 만들어졌다 (콘텐츠 공급)

셋은 피드백 루프로 얽혀 있다. 사용자의 취향이 추천을 만들고, 추천이 콘텐츠 생산에 영향을 주고, 그것이 다시 사용자 행동과 알고리즘 학습에 영향을 준다. 리뷰 [[1](#ref-1)]는 "이 질문은 사용자의 참여 패턴을 관찰하는 것만으로는 풀 수 없다"고 단언한다. 그래서 반사실이 필요하다.

## 5.2 반사실과 기준선

**반사실(counterfactual)** 은 "실제로는 일어나지 않았지만, 만약 그랬다면 일어났을 상황"이다. "YouTube 알고리즘이 사용자를 극단 콘텐츠로 밀어넣었다"고 말하려면, 같은 사용자가 알고리즘 없이 행동했을 때 무엇을 봤을지를 알아야 한다. 그래야 "알고리즘 때문에 더 본 것"이 얼마인지 계산할 수 있다. 같은 사람이 동시에 두 세계를 살 수는 없으니, 이 "없었을 때의 세계"를 대신할 비교 대상이 필요하다. 그것이 **반사실 기준선(counterfactual baseline)** 이다 [[1](#ref-1), [43](#ref-43)].

리뷰 [[1](#ref-1)]가 언급하는 기준선의 예는 다음과 같다.

| 기준선 | 뜻 | 사용 예 |
|---|---|---|
| 역시간순 추천 | 팔로우한 계정의 글을 최신순으로만 보여줌 | Huszár 외 [[31](#ref-31)], Meta 2020년 연구 [[33](#ref-33)], Gauthier 외 [[54](#ref-54)] |
| 무작위 추천 | 알고리즘이 취향을 전혀 반영하지 않았다면 | 주로 시뮬레이션 |
| 예전 버전의 랭킹 시스템 | 알고리즘을 바꾸기 전과 후를 비교 | 플랫폼 내부 |

핵심은 "증폭됐다"는 주장에는 늘 "무엇에 비해서"라는 단서가 붙어야 한다는 것이다. 기준선을 무엇으로 잡느냐에 따라 같은 데이터에서도 "증폭" 여부가 달라진다 [[43](#ref-43)].

역시간순 추천의 뜻과 한계는 3장 용어집에 정리해 두었다. 요점만 되풀이하면, 역시간순 추천은 "알고리즘이 손대지 않은 피드"의 대용으로 가장 널리 쓰이지만 중립은 아니다. 글을 자주 올리는 계정에 유리하고, 언제 접속하느냐에 좌우되며, 팔로우 목록(그 자체가 과거 알고리즘 추천의 산물일 수 있는)을 그대로 반영한다 [[43](#ref-43), [54](#ref-54)].

## 5.3 두 가지 실험 전략

리뷰 [[1](#ref-1)]는 관찰 데이터를 "신중하게 검증된 인과 설계"와 결합하는 두 전략을 제시한다. 두 전략은 서로 거울에 비친 모습이다.

| | 전략 1 | 전략 2 |
|---|---|---|
| 무엇을 바꾸나 | 알고리즘 | 사용자 행동 |
| 무엇을 고정하나 | 사용자 행동 | 알고리즘 |
| 무엇을 재나 | 알고리즘 증폭의 몫 | 사용자 선택의 몫 |
| 대표 구현 | 상대적 알고리즘 증폭 [[31](#ref-31)] | Counterfactual bot [[45](#ref-45)] |
| 플랫폼 협력 | 원칙적으로 필요 (우회로 있음) | 필요 없음 |

## 5.4 전략 1: 상대적 알고리즘 증폭

### 개념 정의

리뷰 [[1](#ref-1)]가 인용한 Stray, Thorburn과 Bengani [[43](#ref-43)]의 정의는 이렇다. **"사용자 행동을 고정한 채, 한 알고리즘에서 나타나는 콘텐츠 분포가 다른 알고리즘에서의 분포와 비교해 얼마나 달라지는가."** 이 글 자체는 수식을 주지 않고, 측정치가 갖춰야 할 다섯 조건만 제시한다.

1. 어떤 콘텐츠 집합을 볼 것인지 정한다.
2. 기준선 알고리즘을 밝힌다. "누구나 인정하는 옳은 기준선, 중립적인 기준선은 없다."
3. 결과 변수는 참여(engagement)가 아니라 노출(impressions)로 잡는다. 사용자는 피드 내용을 거의 통제하지 못하므로, 노출이 알고리즘의 특성을 더 잘 드러낸다.
4. 알고리즘 효과와 사용자 행동을 가른다.
5. 효과가 안정되기까지의 시간 범위를 밝힌다.

### 실제 계산: Huszár 외 (2022)

가장 잘 알려진 구현이다 [[31](#ref-31)]. Twitter가 2016년에 알고리즘 추천 타임라인을 도입하면서 그 뒤로 계속 유지해 온 홀드백 실험을 이용했다.

| 항목 | 내용 |
|---|---|
| 실험 대상 | 전 세계 계정의 5% |
| 대조군 | 그중 20%. 역시간순 추천 타임라인만 봄 (약 1,160만 계정) |
| 처치군 | 그중 80%. 알고리즘 추천 타임라인 (약 4,650만 계정) |
| 도달(reach) | 하루 동안 트윗 집합 T 가운데 하나라도 본 사용자 수 |
| "봤다"의 기준 | 트윗 UI의 50% 이상이 500밀리초 이상 화면에 표시됨 |
| 기간 | 90일 동안 날마다, 국가별로 계산 |

증폭률 공식(원문 SI Section D)은 다음과 같다.

$$
a_d(T) = \left( \frac{\lvert U_{T,d} \cap U_{\mathrm{treatment}} \rvert + 1}{4\,\lvert U_{T,d} \cap U_{\mathrm{control}} \rvert + 4} - 1 \right) \times 100\%
$$

- $U_{T,d}$: $d$일에 트윗 집합 $T$ 가운데 하나라도 본 사용자 집합
- $U_{\mathrm{treatment}}$, $U_{\mathrm{control}}$: 처치군과 대조군 사용자 집합
- 분모의 4: 처치군이 대조군보다 4배 크기 때문에 넣는 정규화 항
- $+1$과 $+4$: 0으로 나누는 것을 막는 스무딩

본질은 다음과 같다.

$$
a_d(T) \approx \left( \frac{\Pr[\text{treatment 사용자가 } T \text{를 봄}]}{\Pr[\text{control 사용자가 } T \text{를 봄}]} - 1 \right) \times 100\%
$$

- 0%: 두 피드에서 볼 확률이 같다.
- 50%: 알고리즘 추천 피드 사용자가 그 트윗을 볼 확률이 50% 높다.
- 음수: 알고리즘이 오히려 덜 보여준다.

**숫자 예시.** 대조군 1,000명 가운데 100명이 어떤 정치인의 트윗을 봤고, 처치군 4,000명 가운데 600명이 봤다면, 도달 비율은 10% 대 15%다. 스무딩을 무시하면 증폭률은 $\left( \frac{600}{4 \times 100} - 1 \right) \times 100\% = 50\%$ 다.

정당 소속 정치인 전체의 트윗을 하나의 집합으로 묶으면 **집단 증폭**, 정치인 한 명씩 계산하면 **개인 증폭**이다. 집단 증폭은 활발하게 활동하는 소수 계정에 좌우될 수 있어서, 저자들은 부트스트랩 재표집과 순열 검정으로 집단 간 비교가 튼튼한지 확인했다 [[31](#ref-31)].

### 결과

| 국가 | 우파 정당 | 좌파 정당 |
|---|---|---|
| 캐나다 | 보수당 167% | 자유당 43% |
| 영국 | 보수당 176% | 노동당 112% |

7개국 가운데 6개국에서 우파 정당이 좌파보다 높게 증폭됐고, 독일만 차이가 없었다. 다만 개인 수준에서는 소속 정당과 증폭률 사이에 상관이 없었다. 집단 비교와 개인 비교가 "겉보기에 다른 결론"으로 이어진다는 점을 저자들이 명시한다. 정치적 극단이 중도보다 더 증폭된다는 증거는 없었다 [[31](#ref-31)].

### 주의할 점

- **기준선 선택이 결과를 바꾼다.** 역시간순 추천도 중립이 아니다 [[43](#ref-43)].
- **노출만 잰다.** 반응이나 태도 변화는 별도의 증거가 필요하다 [[1](#ref-1)].
- **"사용자 행동 고정"은 근사일 뿐이다.** 처치군 사용자는 시간이 지나면서 알고리즘에 맞춰 팔로우나 클릭 습관이 바뀐다. 장기 피드백은 이 방법으로 잡히지 않는다. 그래서 리뷰 [[1](#ref-1)]는 이 방법과 전략 2를 서로 보완하도록 함께 쓰라고 권한다.

## 5.5 전략 2: Counterfactual bot

### 절차

리뷰 제1저자의 2024년 *PNAS* 연구 [[45](#ref-45)]가 원형이다. YouTube를 대상으로 했다.

1. 실제 사용자 패널의 시청 이력을 확보한다.
2. 로그인한 봇에 그 이력을 그대로 재생해 개인화 상태를 만든다. 이 시점에서 봇은 "실제 사용자"를 흉내 낸다.
3. 봇을 두 갈래로 나눈다. 한쪽은 실제 사용자의 행동을 계속 따르고(사용자의 선택 보존), 다른 쪽은 "이제부터 추천만 클릭하라"는 규칙을 따른다(사용자의 선택 없음).
4. 두 봇이 이후에 무엇을 보는지 비교한다.

여기서 반사실 기준선은 알고리즘 버전이 아니라 **사용자 행동 규칙**이다. "사용자가 자기 의지 없이 알고리즘 추천만 따랐다면" 보게 됐을 세계를 봇이 보여준다. 실제 노출과 봇 노출의 차이가 곧 사용자가 스스로 선택해서 만든 몫이다. 알고리즘은 실제 서비스 그대로 두니 플랫폼 협력이 필요 없다 [[45](#ref-45)].

### 결과

추천만 따르는 봇은 취향이 극단적인 사용자를 더 온건한 콘텐츠로 이끌었고, 온건한 사용자에게는 사실상 중립적이었다. 다시 말해 관찰된 극단 콘텐츠 소비의 대부분은 알고리즘이 아니라 사용자 선택의 산물이었다 [[45](#ref-45)].

### 주의할 점

- 봇은 "실제 사용자 경험이 아니라 알고리즘의 공급을 잰다"(리뷰 [[1](#ref-1)] 원문).
- 로그인 계정이 필요하고, 약관 위반과 봇 차단 위험이 있다 [[1](#ref-1)].
- 시드 콘텐츠, 계정의 로그인 상태, 실험 기간 같은 사소한 결정이 결과를 뒤집을 수 있다 [[1](#ref-1), [69](#ref-69)].

## 5.6 확장: 디지털 트윈과 LLM 에이전트

리뷰 [[1](#ref-1)]는 전략 2를 두 단계로 넓히자고 제안한다.

**디지털 트윈.** 실제 사용자의 행동 패턴으로 만든 계산적 복제본이다. 의사결정 규칙을 "뇌", 자동화 계정을 "팔"로 삼아 추천 시스템과 오랫동안 되풀이해서 상호작용시킨다. 플랫폼의 안전 기능과 피드백 루프의 형성을 대규모로 통제해서 검증할 수 있다 [[62](#ref-62)].

**LLM 기반 에이전트.** 규칙 대신 대규모 언어모델이 추천에 반응해 콘텐츠 선택을 그때그때 결정한다. 정치 성향, 자극에 대한 민감도, 반대 의견에 대한 호기심을 다양하게 설정할 수 있다 [[57](#ref-57), [58](#ref-58), [59](#ref-59)]. 이렇게 하면 "알고리즘이 문제적 콘텐츠를 증폭하는가"만이 아니라 "누구에게, 어떤 행동 조건에서" 증폭이 일어나는지를 연구할 수 있다 [[60](#ref-60), [61](#ref-61)].

### 사람 대신인가, 사람을 보완하는가

학습 대화에서 나온 질문이다. 답은 "보완"이다. 리뷰 [[1](#ref-1)]는 "LLM 기반 에이전트는 인간 피험자를 완전히 대체할 수 없다"고 못 박고, 쓸 곳을 다음으로 한정한다.

- 사람에게 윤리적으로 시킬 수 없는 민감한 주제
- 몇 달, 몇 년이 걸리는 장기 피드백 (단기 실험실 실험과 오래 이어지는 실제 행동 사이의 빈틈을 메움)
- 랭킹 목표, 조정 정책, 인터페이스 변경 같은 반사실 시나리오를 체계적으로 탐색하는 일
- 관찰 연구와 현장실험을 "보완"하는 역할

### 벤치마크가 필요한 이유

에이전트의 클릭 패턴, 체류 시간, 알고리즘 압력 아래서의 콘텐츠 선택이 실제 사람과 같은지는 "대부분 검증되지 않았다." 그래서 리뷰 [[1](#ref-1)]는 데이터 기부나 브라우저 패널에서 얻은 실제 행동 기록과 에이전트를 맞대어 보는 벤치마크를 제안한다. 이 벤치마크는 평균적인 노출·참여 패턴만이 아니라, 문제적 소비의 대부분을 차지하는 소수 집단의 행동까지 재현하는지를 봐야 한다. 이런 벤치마크를 만들고 검증하는 것 자체가 "앞으로의 중요한 연구 방향"이다.

이것이 3장에서 설명한 "외적 타당도 미검증"의 정확한 뜻이다. 시뮬레이션 안에서 얻은 결과가 실제 세계에도 들어맞는지 아직 아무도 확인하지 않았고, 그 확인 방법을 만드는 것이 과제다.

## 5.7 방법 비교표

| 방법 | 플랫폼 협력 | 무엇을 바꾸나 | 무엇을 재나 | 주요 한계 |
|---|---|---|---|---|
| 내부 A/B 테스트 [[31](#ref-31), [33](#ref-33)] | 필요 | 알고리즘 | 노출, 참여, 태도 | 소수 연구자만 접근, 일회성 |
| 사용자 토글 실험 [[54](#ref-54)] | 필요 없음 | 알고리즘 (제공된 옵션 안에서) | 노출, 참여, 태도 | 참가자가 치우침, 기준선 제한, 지시 이행이 자기보고 |
| 브라우저 확장 프로그램 [[39](#ref-39), [47](#ref-47)] | 필요 없음 | 노출 (클라이언트 쪽) | 노출, 참여 | 표본이 작음, 참여자 편향 |
| 손인형(sock puppet) [[12](#ref-12), [40](#ref-40)] | 필요 없음 | 봇 행동 | 공급 | 개인화 상태 없음 |
| Counterfactual bot [[45](#ref-45)] | 필요 없음 | 사용자 행동 규칙 | 공급 (개인화된) | 실제 경험 아님, 약관 위험 |
| 디지털 트윈 / LLM 에이전트 (실제 플랫폼 연결) [[1](#ref-1)] | 필요 없음 | 사용자 행동 | 공급 | 봇과 같음 + 사람과의 유사성 미검증 |
| 완전 시뮬레이션 [[60](#ref-60), [61](#ref-61)] | 필요 없음 | 둘 다 | 시뮬레이션 안의 모든 것 | 외적 타당도 미검증 |

## 5.8 설계 점검표

리뷰 [[1](#ref-1)]의 권고 3을 질문 형태로 바꾼 것이다. 인과 연구를 설계할 때 각 항목에 답할 수 있어야 한다.

1. 관심 콘텐츠는 무엇이며 어떻게 정의하고 분류하는가?
2. 비교 기준선은 무엇인가? 왜 그것인가? 그 기준선에는 어떤 편향이 있는가?
3. 결과 변수는 공급, 노출, 참여, 효과 가운데 무엇인가?
4. 사용자 행동은 고정하는가, 바꾸는가? 어떻게?
5. 효과가 안정되기까지 얼마나 걸린다고 가정하며, 실험 기간은 그것을 담는가?
6. 관찰 분석, 통제 실험, 가상 사용자 가운데 무엇을 결합하는가?
7. 측정 도구(분류기, LLM)는 이 영역에서 검증됐는가? 오류율은 얼마인가?
8. 결론은 어느 집단, 어느 기간, 어느 플랫폼에 한정되는가?

## 5.9 인간-알고리즘 상호작용 모델: 논문의 개념 모델과 교재의 형식화

리뷰 [[1](#ref-1)]는 사용자와 알고리즘이 서로를 어떻게 만들어 가는지를 세 가지 개념 모델로 설명한다. 이 모델들은 논문에서 **서술로만** 제시되며, 논문에는 수식이 하나도 없다. 아래에서는 논문의 서술을 먼저 옮기고, 그 다음에 교재가 이해를 돕기 위해 형식화한 수식을 덧붙인다. 수식은 교재의 표현이지 논문의 것이 아니다.

### (1) 피드백 루프 모델 (Fig. 2)

논문의 Fig. 2는 사용자와 추천 알고리즘 사이의 순환을 네 경로로 그린다 [[1](#ref-1)].

| 경로 | 내용 | 다른 요인 |
|---|---|---|
| a | 사용자가 플랫폼에서 선택한다 (콘텐츠 선택, 상호작용, 반응) | 취향, 호불호, 편향, 인식, 인간관계, 오프라인 활동 |
| b | 그 행동 신호가 추천 알고리즘의 주된 입력이 된다 | |
| c | 알고리즘이 개인화된 추천을 내놓아 노출, 인간관계, 참여 궤적을 만든다 | 외부 사건, 정책 변경, 그 밖의 미지 요인 |
| d | 누적된 알고리즘의 영향이 사용자의 태도, 신념, 오프라인 행동을 바꾸고, 그것이 다시 온라인 취향과 선택을 바꾼다 | |

논문의 요지는 두 가지다. 첫째, 경로 d(알고리즘이 사용자에게 미치는 영향)는 많이 연구됐지만, 경로 a(사용자가 이 순환을 시작하고 이어 가는 역할)는 "심각하게 연구가 부족하다." 둘째, 이 순환 때문에 "관찰된 취향은 알고리즘과 무관하게 생긴 것이 아니다." 지금의 수요는 과거 추천이 만든 것일 수 있으므로, 수요는 "현재 소비 패턴의 기술"로만 읽어야지 "취향이 원래 그랬다"는 주장으로 읽으면 안 된다 [[1](#ref-1)].

**교재의 형식화.** 사용자 $i$의 시점 $t$ 상태를 $\theta_i^{(t)}$(취향, 편향, 인간관계), 행동을 $a_i^{(t)}$, 받은 추천을 $r_i^{(t)}$, 플랫폼 전체의 콘텐츠 공급을 $S^{(t)}$라 하면 Fig. 2는 다음 세 함수의 되풀이로 쓸 수 있다.

$$
a_i^{(t)} = g\!\left(\theta_i^{(t)},\, r_i^{(t)},\, \varepsilon_i^{(t)}\right) \quad \text{(경로 a: 사용자의 선택)}
$$

$$
r_i^{(t+1)} = f\!\left(a_i^{(1)}, \ldots, a_i^{(t)};\, S^{(t)}\right) \quad \text{(경로 b, c: 알고리즘의 학습과 추천)}
$$

$$
\theta_i^{(t+1)} = h\!\left(\theta_i^{(t)},\, r_i^{(t)},\, a_i^{(t)}\right) \quad \text{(경로 d: 태도의 변화)}
$$

여기서 $\varepsilon$은 논문이 말하는 "어느 정도의 우연"이다. 이 표기로 논문의 두 요지를 다시 쓰면, 기존 연구는 $h$를 주로 다뤘고 $g$는 덜 다뤘다는 것, 그리고 $h$가 항등함수가 아니므로 $\theta$를 고정된 외생변수로 취급할 수 없다는 것이다. 5.4절의 전략 1은 $g$를 고정하고 $f$를 바꾸는 것이고, 5.5절의 전략 2는 $f$를 고정하고 $g$를 바꾸는 것이다.

### (2) 공급과 수요 모델: 양면 시장

논문 [[1](#ref-1)]은 플랫폼을 "사용자의 콘텐츠 수요와 생산자의 공급 의지를 이어 주는 시장"으로 본다 [[8](#ref-8), [9](#ref-9), [71](#ref-71)]. 중요한 단서는 플랫폼이 "중립적 중개자가 아니라 시장을 능동적으로 설계하는 주체"라는 것이다. 무엇을 최적화할지(최적화 목표)와 어떤 선택지를 어떻게 배치할지(선택 구조)를 정함으로써, 플랫폼은 콘텐츠가 어떻게 공급되는지와 사용자 수요가 어떻게 생기는지 양쪽에 모두 손을 댄다. 따라서 "수요를 소비의 원인 가운데 하나로 본다"는 말이 "수요는 플랫폼과 무관하다"는 뜻은 아니다.

**교재의 형식화.** 관찰된 소비 $C$를 수요 $D$와 공급 $S$의 매칭 결과로 쓰되, 알고리즘 $f$가 세 곳 모두에 들어간다.

$$
C = M_f\!\big(\, D(\theta, f),\; S(\pi, f) \,\big)
$$

$D$는 사용자 취향 $\theta$와 알고리즘 $f$의 함수이고(취향이 추천에 의해 만들어지므로), $S$는 생산자의 유인 $\pi$와 $f$의 함수이며(생산자가 알고리즘에 맞춰 콘텐츠를 만들므로), $M_f$는 $f$가 정하는 매칭 규칙이다. "알고리즘 탓인가, 사용자 탓인가"라는 질문이 왜 단순하지 않은지가 이 식에 드러난다. $f$를 바꾸면 $M_f$만 바뀌는 것이 아니라 $D$와 $S$도 함께 바뀐다.

### (3) 목적함수 재설계

논문 [[1](#ref-1)]의 권고 6은 추천 시스템이 무엇을 최적화하는지를 다시 묻는다. 플랫폼은 클릭, 시청 시간, 세션 길이 같은 참여를 만족의 대리 지표로 써 왔지만, 사람은 장기적으로 원하는 것과 어긋나는 선택을 자주 한다 [[49](#ref-49)]. 그래서 순간의 참여와 지속되는 삶의 질을 구분하는 새 이론과 실증이 필요하다. 나아가 추천 시스템의 목적함수를 "순수하게 개인적이거나 상업적인 가치가 아니라 사회적 가치를 반영하도록" 재정의해야 한다 [[70](#ref-70)]. 다양성 [[79](#ref-79)]이나 공정성 [[80](#ref-80)]을 겨냥한 다목적 최적화 틀이 이미 있지만, 대부분 Amazon, Netflix, Spotify 같은 상업·오락 벤치마크에서 개발되고 평가됐다. 논문은 이것을 노출 다양성과 정보의 온전함이 민주주의에 중요한 뉴스·공적 정보 영역으로 넓히자고 제안한다.

**교재의 형식화.** 알고리즘 $f$를 고를 때의 목적을 참여 $E$, 다양성 $\mathrm{Div}$, 해악 $\mathrm{Harm}$의 가중합으로 쓰면 다음과 같다.

$$
\max_{f \in \mathcal{F}} \;\sum_{i=1}^{N} \Big[ E_i(f) + \lambda_1 \,\mathrm{Div}_i(f) - \lambda_2 \,\mathrm{Harm}_i(f) \Big]
$$

그리고 Kleinberg 외 [[49](#ref-49)]의 문제의식은 참여 $E_i$와 장기 복지 $W_i$가 다르다는 것이므로, 다음 두 문제의 해가 다를 수 있다는 것이 핵심이다.

$$
f_E^{*} = \arg\max_{f} \sum_i E_i(f), \qquad f_W^{*} = \arg\max_{f} \sum_i W_i(f), \qquad f_E^{*} \neq f_W^{*}
$$

논문이 요구하는 것은 $W$가 무엇인지(디지털 환경에서 복지란 무엇인가)를 이론적으로 분명히 하고, 콘텐츠 설계와 노출과 결과를 잇는 실증 측정으로 $W$를 잴 수 있게 만드는 일이다. 가중치 $\lambda$를 어떻게 정할지, $\mathrm{Harm}$을 누가 정의할지는 열린 문제이며, 논문은 답을 주지 않는다.

### 주의: 논문에 있는 것과 없는 것

이 논문을 요약한 2차 자료 가운데는 위와 비슷한 수식이 논문에 실린 것처럼 쓰거나, 논문이 "BERT나 GPT 기반 임베딩으로 편향을 수치화하고 토픽 모델링과 연계하는 파이프라인"을 권한다고 쓴 것이 있다. 원문 [[1](#ref-1)]의 본문 16쪽 전체를 텍스트로 추출하고, PDF에 수학 글꼴이나 수식 이미지가 포함돼 있는지까지 확인한 결과는 다음과 같다.

| 2차 요약의 주장 | 원문 확인 결과 |
|---|---|
| 플랫폼을 양면 시장으로 정의하고, 사용자의 내적 선호가 수요를, 생산자의 수익 추구가 공급을 만들며, 알고리즘이 둘을 매칭한다 | **있음.** 서술로 제시된다. "플랫폼은 사용자의 콘텐츠 수요와 생산자의 공급 의지를 매칭하는 시장 역할을 한다", "최적화 목표와 선택 구조를 설계함으로써 공급과 수요 양쪽을 형성한다", "광고 유인과 참여 지표가 공급과 수요를 함께 만드는 양면 시장"이라는 문장이 있다. 수식은 없다. |
| 알고리즘 무작위 배정(feed-randomization), counterfactual bot, 디지털 트윈과 에이전트 기반 모델링 | **있음.** Table 1에 "feed-randomization, counterfactual-bot and field experiments"가, 권고 절에 두 가지 인과 식별 전략과 디지털 트윈("뇌"와 "팔"), LLM 기반 에이전트가 서술된다. |
| 효용 최대화식 $\max_{f \in F} \sum_{i=1}^{N} U(c_i \mid a_i, f)$ | **없음.** 본문에 수식이 하나도 없다. "max"는 "engagement-maximizing", "maximize profits" 같은 일반 단어로만 6회 나오고, $U$, $\sum$, $\lambda$, "utility", "loss", "equation", "formula" 같은 토큰은 수식의 뜻으로 한 번도 나오지 않는다. PDF의 글꼴 목록에도 수학 글꼴이 없고, 삽입된 이미지는 그림 1·2의 그래픽뿐이다. |
| 문제적 콘텐츠 노출은 1% 미만의 소수가 80%를 차지하는 롱테일 분포 | **있음.** 사용자 1%가 가짜뉴스 소비의 80%를, 0.6%가 극단주의 채널 시청 시간의 80%를 차지한다는 수치가 인용되고, "롱테일"이라는 표현도 쓰인다. |
| 케이블 TV에서도 비슷한 에코챔버가 관찰되므로 사용자 취향의 결과일 가능성 | **있음.** "케이블 TV 뉴스 소비에서 나타나는 당파적 에코챔버의 크기와 비슷하다"는 문장이 있다. |
| 데이터 접근 제한과 짧은 실험 기간이 장기 누적 효과 측정을 방해 | **있음.** 걸림돌 절과 권고 절에 서술된다. |
| National Internet Observatory 같은 독립 연구 인프라 | **있음.** 권고 5에 "유망한 첫걸음"으로 언급된다. |
| 도메인 수준 대신 LLM을 활용한 콘텐츠 수준 분석 | **있음.** "콘텐츠 자체에 근거한 분류가 이상적이며 LLM이 이를 가능하게 하되 새로운 검증 부담이 따른다"고 쓴다. 또한 transformer 계열 방법과 LLM이 주제, 당파성, 감정을 재는 데 "이전 세대보다 분명히 우수하다"고 인정하되, zero-shot이나 few-shot 라벨을 오류 없는 것으로 가정하면 결론이 왜곡된다고 경고한다. |
| BERT나 GPT 임베딩으로 편향을 수치화하고 토픽 모델링과 연계하는 파이프라인 개발 권장 | **없음.** "BERT", "GPT", "embedding"이라는 단어는 본문에 없다. "topic model"은 LDA와 STM을 검증 없이 쓰는 관행을 비판하는 맥락으로만 나온다. 논문의 Code availability 절은 "이 리뷰에서 새로 만들거나 분석한 코드는 없다"고 밝힌다. |
| 다목적 최적화: CTR만이 아니라 다양성과 공정성을 제약 조건으로 | **부분적으로 있음.** "다양성이나 공정성을 촉진하는 새 최적화 틀"이 상업·오락 벤치마크에서 개발됐으며 뉴스·공적 정보 영역으로 "다목적 최적화 틀을 확장할 수 있다"고 쓴다. "CTR"이나 "제약 조건"이라는 표현은 없다. |
| 손실함수 $\mathcal{L} = \text{Engagement} + \lambda_1 \cdot \text{Diversity} - \lambda_2 \cdot \text{Harmfulness}$ | **없음.** 위와 같은 이유로 수식 자체가 없다. |
| "알고리즘은 중립적이지 않으나 모든 사회적 문제의 근원도 아니다" | **취지는 있음.** "플랫폼은 중립적 중개자가 아니다"와 "현재 증거는 알고리즘이 문제적 결과의 지배적 원인이라는 강한 주장을 뒷받침하지 않는다"는 두 문장을 합친 요약이다. 이 문장 그대로는 없다. |

요약하면, 2차 요약의 개념적 내용은 대체로 논문에 있지만, 두 수식과 "BERT/GPT + 토픽 모델링 파이프라인" 권장은 요약자가 덧붙인 것이다. 논문이 권하는 것은 "출처 수준이 아니라 콘텐츠 수준의 분석"과 "어떤 도구든 오류율을 평가하고 검증하라"는 원칙이지, 특정 모델이나 목적함수가 아니다. 이 절의 형식화 수식도 같은 의미에서 교재의 표현이다. 2차 자료를 읽을 때는 원문과 대조하는 습관이 필요하다.
